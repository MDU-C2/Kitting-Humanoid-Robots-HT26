Instructions for connecting a host computer to the Unitree G1 over Ethernet, gaining 
internet access on the robot's dev computer, and transferring/running code on it.

1. Physical Connection
    Connect an Ethernet cable from your computer into port [4] or [5] on the Unitree 
    G1. If you are not sure which port is which, consult the Unitree G1 manual. 

2. Test the Link
    Write this in terminal to test the connections:
        ping 192.168.123.161    # Locomotion Computer   (Can't access)
        ping 192.168.123.164    # Developer Computer    (User: unitree, Password: 123)
        ping 192.168.123.20     # 360° Lidar
    
    
    If you are connecting a new computer, you may need to configure its IP adress.
    As the robot dosen't have a build-in DHCP server, you will likely need to set a
    static IP (e.g. 192.168.123.222). Once configured, this should persist automatically.
    It only breaks if the network profile itself gets deleted or the adapter changes.
    Read the offical Unitree G1 documentation for setting the IP adress.

3. SSH into the G1
    Write in the terminal to remote access the dev computer:
        ssh -X unitree@192.168.123.164
    
    You may be asked to choose a ROS distribution, select "1" for Foxy.

4. Internet Access on the Dev Computer
    This is needed for installs, apt, or pip on the dev computer. You can skip this 
    section if you don't need to install or update anything. This setup does NOT persist,
    it resets whenever the dev computer reboots, and also resets on your host computer if
    it sleeps or reconnects to wifi.

    On your computer, write in the terminal:
        sudo sysctl -w net.ipv4.ip_forward=1
        sudo iptables -t nat -A POSTROUTING -o wlp0s20f3 -j MASQUERADE
        sudo iptables -A FORWARD -i enx50a03000b0dc -o wlp0s20f3 -j ACCEPT
        sudo iptables -A FORWARD -i wlp0s20f3 -o enx50a03000b0dc -m state --state RELATED,ESTABLISHED -j ACCEPT
    
    On the dev computer (over your SSH session), write in the terminal:
        sudo ip route add default via 192.168.123.222   
        echo "nameserver 8.8.8.8" | sudo tee /etc/resolv.conf
    
    To verify the connection, write in the terminal:
        ping -c 3 8.8.8.8
        ping -c 3 pypi.org

    If no errors comes up it should mean the dev computer has internet access.

5. Transferring Code/File to the Unitree G1
    To run code on the robot, first send a copy of that code/file to the robot:
        cd ~/<FILE_LOCATION>
        scp ~/<FILE_NAME> unitree@192.168.123.164:~/

    To edit a file on the robot:
        nano <FILE_NAME>
        Save and exit with "Ctrl + O", "Enter", then "Ctrl + X".

    To remove a file on the robot:
        rm <FILE_NAME>

    To install or update packages on the robot: 
        sudo apt insatll <PACKAGE_NAME>
        sudo apt uptade

6. Running code
    Example: running "G1_data_collector.py" to connect to the depth camera on the G1.

    Write in the terminal:
        source ~/miniconda3/bin/activate ~~teleimager~~
        sudo systemctl stop teleimager.service  # Turn off previous process holding the camera port
        python3 G1_data_collector.py
