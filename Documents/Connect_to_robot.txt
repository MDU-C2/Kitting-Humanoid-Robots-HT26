This is an instruction to how to connect to the Unitree G1 via Ethernet

1. Physical Connection
    Connect an ethernet cable from the computer into port [4] or [5] on the G1.
    If you are not sure which port is which, consult the Unitree G1 manual. 

2. Test Link
    write in terminal:
        ping 192.168.123.161 # 
        ping 192.168.123.164 #
    
    If you are connecting a new coputer you may need to configure the IP adress.
    As the robot dosen't have a DHCP built-in, you may have change the IP to static ip
    to like 192.168.123.222. Otherwise it should work without configuration. It only 
    breaks if the profile itself gets deleted or the adapter changes.

3. SSH To The G1
    write int the terminal:
        ssh -X [unitree@192.168.123.164]
    
    It may ask which ROS you want to use, chose 1 for foxy.

4. Internet Connection
    This is if you need internet connection for installs, apt, pip.
    This part resets on the dev-computer in the robot and also resets on your computer
    if it sleeps/reconnects to wifi.

    On your computer write in the terminal:
        sudo sysctl -w net.ipv4.ip_forward=1
        sudo iptables -t nat -A POSTROUTING -o wlp0s20f3 -j MASQUERADE
        sudo iptables -A FORWARD -i enx50a03000b0dc -o wlp0s20f3 -j ACCEPT
        sudo iptables -A FORWARD -i wlp0s20f3 -o enx50a03000b0dc -m state --state RELATED,ESTABLISHED -j ACCEPT
    
    On the dev-computer (over your SSH session) write in the terminal:
        sudo ip route add default via 192.168.123.222   
        echo "nameserver 8.8.8.8" | sudo tee /etc/resolv.conf
    
    To verify the connection, write in the terminal:
        ping -c 3 8.8.8.8
        ping -c 3 pypi.org

    If you don't get any errors it should work.

5. Run code
    To run codes, for example view_pic_g1_cam.py for connecting to the depth camera on
    the Unitree G1.

    Write int the terminal:
        source ~/miniconda3/bin/activate ~~teleimager~~
        sudo systemctl stop teleimager.service         # Turn off previous work process, blocks the camera port
        python3 view_pic_g1_cam.py
