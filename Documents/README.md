# Documents

Overview of what's stored in this folder.

## Contents
- **Templates**: Standard templates used across the project, including the project paper template and project plan template. 
- **Contracts**: Signed agreements and contract documents related to the project.
- **Presentations**: Google Slides used for project presentations and demos. 
- **Instructions**: Setup and guides.
- **Standups**: Notes and summaries from standup mettings.
